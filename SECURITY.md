# Security policy

## Supported versions

Security fixes are made against the current `main` branch. No released version is currently maintained separately.

## Reporting a vulnerability

Do not disclose a suspected vulnerability in a public issue. Use GitHub's private vulnerability reporting feature when it is enabled for this repository; otherwise, contact the repository owner privately through GitHub and include reproduction steps, affected version or commit, impact and any proposed mitigation.

The maintainer aims to acknowledge reports within seven calendar days. Please allow time for a fix and coordinated disclosure before publishing details.
